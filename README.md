# 🎯 PR Strategy Master - Communicatiestrategie Game

Een interactieve game voor 17-jarige leerlingen waarin ze leren communicatiestrategieën toe te passen. Gebaseerd op de **12 strategieën van Wil Michels**.

## 🚀 Hoe Spelen?

### Optie 1: Direct via GitHub Pages (AANBEVOLEN)
https://taalstaalkanaal.github.io/PRStrategiespel/

### Optie 2: Lokaal downloaden
1. Download het `index.html` bestand
2. Open het met je browser (dubbelklik op het bestand)
3. Klaar om te spelen!

## 🎮 Wat zit in de Game?

**12 Real-World Cases** met stijgende moeilijkheid:

### Gemakkelijk (Cases 1-3):
- 📱 TikTok Trend Fail → Reputatiestrategie
- 🏨 Nieuw Hotel → Positioneringsstrategie  
- 😔 Demotivatie Werknemers → Familiestrategie

### Medium (Cases 4-7):
- 🎮 Kleine Brand vs Gamers → Ambassadeurstrategie
- 🎪 Festival Pop-up → Brandactivatiestrategie
- 👨‍🍳 Restaurant Mond-tot-Mond → Word-of-Mouthstrategie
- 🍎 Apple-Fans Viral → Fanstrategie

### Moeilijk (Cases 8-12):
- 🚨 Voedselvergiftiging Crisis → Issuemanagementstrategie
- 🌟 Medewerkers Merkaambassadeurs → Internal Branding
- 🏛️ Gemeentelijk Plein → Participatiestrategie
- 🏢 Beleidsmakers Overtuigen → Public Affairs
- 💻 Digitaal Platform School → Veranderstrategie

## ✨ Kenmerken

✅ **Twee vraaglagen per case:**
1. Welke communicatiestrategie past het best?
2. Welk communicatiemiddel zou je gebruiken?

✅ **Antwoorden in random volgorde** (juist antwoord niet steeds eerst)

✅ **Uitgebreide feedback** na elke vraag met uitleggen

✅ **Interactief scoreboard** met motiverende boodschappen

✅ **Geen login nodig** - direct speelbaar

✅ **Responsive design** - werkt op mobiel, tablet & desktop

✅ **Gebaseerd op Wil Michels' theorie** over communicatiestrategieën

## ⏱️ Speelduur
Ongeveer **15-20 minuten** per game
